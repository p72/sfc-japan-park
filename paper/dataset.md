# 朴モデルのデータセット

朴勝俊のストック＆フロー・一貫マクロ計量モデルが何のデータを、どこから、どう加工して
使っているかを、3本の論文の記述からまとめた覚え書き。末尾に本実装（Python版）との
対応と食い違いを置く。

出典：朴(2025c) 2章・付録変数表、朴(2026a) 2章・4章・5章・付録、朴(2026) WP65 付録
および著者配布の図表訂正。本実装の対応は `fetch_*.py` の docstring から。

## 3本の論文とデータの系譜

| 論文 | データについての位置づけ | データ節の差 |
|---|---|---|
| 朴(2025c) No.62、2025年9月 | データセットを新規に構築。2章「使用するデータセット」と巻末の変数表で全容を記述 | — |
| 朴(2026a) No.62 改訂版、2026年1月 | 同じデータセット。データ節の本文は文言の整理のみ（「29年ぶん」「家計は住宅を…」の補足など） | 実質差なし |
| 朴(2026) WP65、2026年4月 | 同じデータセット。推定期間を式ごとに再設定（例：法人ポートフォリオ 2006–2023）。営業余剰を残余式にしたため、統計上の不突合 `SD` をモデル内で使う | 同じ元データ |

**3本とも同じ一つのデータセットを使っている。** 2025c で作られ、2026a はその記述を
整え、WP65 はそれを反実仮想に使った、という関係。

2025c と 2026a のデータ節を機械的に突き合わせた結果、差分は段落の並べ替えと補足の
一文だけで、出典・期間・加工法に変更はなかった。WP65 は本文2章が「2023年度国民経済
計算」を使ったと書くだけで、データ節そのものは持たない（付録と本文で確認）。

## データの流れ

SNA の原表から、モデルが読める形になるまでに4段階ある。

1. **原表** — 国民経済計算：制度部門別勘定（制所・制資）、金融資産・負債の取引と残高、
   固定資本マトリックス、主要系列表
2. **統合** — 資金循環の3表：49品目→7種、8部門→6部門に統合。残高・取引・評価調整
   （調整表は定義式で作る）
3. **派生** — 計算で作る系列：金利・配当率、金融所得、貯蓄・純貸出の調整項、資本ストック
   調整項、統計上の不突合
4. **補完** — SNA 以外：労働力調査、IMF 世界GDP、日銀 実効為替、米国金利、不動産価格指数、
   消費税率、ダミー

## 資金循環の加工

ここが一番手間のかかる部分で、論文は Excel の VBA で処理している
（71行×22列＝1,562系列、30年度ぶんで46,860個）。

### 金融資産を7種に統合（論文 表1）

| 記号 | 名称 | 統合前の項目 |
|---|---|---|
| GSH | 金・SDR・ハイパワードマネー | 貨幣用金・SDR、現金、日銀預け金、政府預金 |
| GB | 国債短証 | 国庫短期証券、国債・財投債 |
| DEP | 預金 | 流動性預金、定期性預金、譲渡性預金、外貨預金 |
| LBD | 融資・債券・デリバティブ | 地方債、政府関係機関債、金融債、事業債、居住者発行外債、CP、信託受益権、債券流動化関連商品（＋貸出・借入、金融派生商品、その他） |
| EQU | 株式等 | 持分・投資信託受益証券 |
| PEN | 保険年金 | 保険・年金・定型保証 |
| NFW | 金融純資産 | — |

表1 の LBD の欄は債務証券の内訳しか印刷されていないが、貸出・借入と金融派生商品、
その他を含めないと部門合計が原表と合わない（本実装での検算）。

### 部門を6つに統合（論文 表2）

| 記号 | 部門 | 中身 |
|---|---|---|
| N | 非金融法人 | 非金融法人企業（公的企業を含む）＋対家計民間非営利団体 |
| CB | 日本銀行 | 「金融機関の内訳」から抜き出す |
| F | 他金融機関 | 日銀以外の金融機関すべて。銀行・投信・証券・保険年金・公的金融機関 |
| G | 一般政府 | 中央政府・地方政府・社会保障基金 |
| H | 家計 | 個人企業を含む |
| W | 海外 | — |

### 純計・評価調整・金

- **純計**：各部門・各資産を「資産−負債」の純額で持つ。変数名は `N + 資産 + A + _部門`
  （例 `NEQUA_H`）。金融純資産は負債側なので `NNFWA` は純資産がプラスの部門でマイナス
- **評価調整（キャピタルゲイン）**は統計に無いので、
  `評価調整_t ＝ 残高_t − 残高_{t−1} − 取引_t` で作る。残高と取引の両方が要るのはこのため
- **金（貨幣用金・SDR）**は対応する負債を持つ部門が無いので GSH の部門合計がゼロにならない
  （2023年度で9,115十億円）。便宜上、全額を日銀が保有すると仮定
- モデル内では取引表は使わない（残高と評価調整だけで動く）

## SNA から計算で作る系列

公表値をそのまま使うのではなく、著者が定義式で作った系列。ここに論文の「作法」が一番出る。

### 金利・配当率（論文 表6）

市場金利の統計は使わない。**「その資産を主に持つ部門の利子・配当 ÷ その資産の残高」**
で、SNA の中だけから作る。利子は「前年度末の残高 × 前年度に決まった金利」で当年度に
受け払いされると考えるので、`t年度の金利 = (t+1年度の利子) ÷ (t年度末の残高)`。
最終年度の値が作れないので、2023年度は2022年度の値で代用。

| 記号 | 何の利回り | 分子（部門・項目） | 分母 |
|---|---|---|---|
| rH | 現金・HPM | — | ゼロとする（日銀当座預金の付利もゼロ） |
| rB | 国債短証 | 一般政府の財産所得（支払）利子 [pp.26–27] | 国債発行額 −NGBA_G |
| rM | 預金 | 家計の財産所得（受取）利子 [pp.30–31] | 家計の預金 NDEPA_H |
| rL | 融資・債券 | 金融機関の財産所得（受取）利子 [pp.24–25] | 金融機関の融資債券純保有 NLBDA_F |
| chi | 株式配当 | **非金融法人**の配当純受取（法人分配所得＋海外直接投資再投資収益、受取−支払）[p.22, p.34] | 前期の NEQUA_N（負値÷負値） |
| psi | 保険年金 | **金融機関**の純保険年金所得（保険契約者帰属投資所得の受払差）[pp.24–25] | 前期の NPENA_F |

実質化はいずれも消費デフレータ PC を差し引く（`RrB = rB − PC`）。

### 金融所得と調整項

- `FINCOME_X = rB·NGBA_X(−1) + rM·NDEPA_X(−1) + rL·NLBDA_X(−1) + chi·NEQUA_X(−1) + psi·NPENA_X(−1)`。
  全部門に同じ利回りを当てるので実績の財産所得とは食い違い、その差は貯蓄の調整項
  `epsilon_X` が吸収する
- `GAPNL_X`：資本勘定から計算した純貸出と金融勘定の純貸出との差。日銀は
  `GAPNL_CB = NL_CB − FINCOME_CB` で、大部分が政府への納付金に相当するが 2025c/2026a は
  モデル化しない（WP65 で政府移転に変更）
- `KCG_X = Kn_X − (Kn_X(−1) + In_X − D_X)`：資本ストックの調整項
- `STR_GAP`、`YR_GAP`：社会移転と実質GDPの合計開差
- 年金受給権調整 `CPEN`、営業余剰の部門シェア `SB2_X`、安全資産の保有シェア
  （GSH/GB/DEP の3分割）なども実績から作った外生変数

## 本実装での対応と食い違い

Python 版は著者のデータセットを使わず、同じ公開統計から独立に組み直している。

### 同じ作法で作っているもの

| 項目 | 論文 | 本実装 |
|---|---|---|
| 資金循環の統合 | Excel VBA で 7種×6部門 | `fetch_ff.py` が ESRI の Excel から同じ統合を行い、原表の合計との一致を毎回検算 |
| 評価調整 | 残高−前期残高−取引 | 同じ定義式 |
| 制度部門別勘定 | 『年報』の項目番号で参照 | 項目名で引く（公表 Excel は部門により番号がずれる）。純貸出の恒等式で検算 |
| 調整項 GAPNL / KCG / epsilon / STR_GAP / YR_GAP | データセット作成時に定義式で計算 | 同じ定義式（`fetch_resid.py`, `fetch_fincome.py`） |
| NEER | 日本銀行 | 日本銀行 時系列統計 API |
| 労働力人口・就業者数 | 労働力調査 長期時系列表（年度平均） | 同じ表の Excel を e-Stat のファイル置き場から直接読む（API キー不要）。列は見出しで探す |
| 資本ストックの年度化 | 0.75 / 0.25 の加重 | 同じ |
| TIME の原点 | 変数表「1994cy=1」 | 同じ |
| 労働時間 W_hours | 毎月勤労統計 2020=100 | e-Stat の指数累積データ（30人以上）。TIME に回帰すると 118.47 − 0.585·TIME で論文の式と一致 |
| 稼働率 LOAD | METI 製造工業稼働率指数 2020=100 | 統計ダッシュボード API から同じ指数。1994年度以降の最大 135.10（論文 135.6667） |
| 世界実質GDP YR_W | IMF WEO 2024年10月の世界成長率を 1994年＝100 の指数に | 同じ版の世界集計を DBnomics（IMF/WEOAGG:2024-10）から取り、同じ手順で指数化。届かなければ IMF DataMapper 最新版、世界銀行 PPP 系列の順に代用 |
| 米国金利 I_US | 米国10年物国債金利（出典の記載なし） | FRED の OECD 系列（IRLTLT01USM156N）。Fed H.15 の10年国債利回り（GS10）と年度平均で完全に一致するので、出典が何であれ同じ数字 |

### いまも違うもの

作り方が論文に書いてあるものは、すべて論文どおりに揃えた（下の履歴）。残っているのは、
論文に作り方が書かれていないか、そもそも同じ数字にはならない性質のもの。

| 項目 | 論文 | 本実装 | どう違うか |
|---|---|---|---|
| 外国人純就業者 N_W | 出典は「労働力調査」とあるが、系列は公表されていない | 論文自身の関係式 W = WB_N/N_N = WB_W/N_W から `N_W = WB_W·N_N/WB_N` で導出 | 著者がどう作ったか不明。論文の定義とは整合するが、同じ数字とは限らない |
| 海外の税 T_W | 変数表の出典欄が空 | ゼロ | 著者の値が不明 |
| 統計上の不突合 SD | 統合勘定 [p.80] の公表値 | `YN − WB_N − TIN_N − B2` で逆算 | 恒等式で決まるので値は同じはず。取り方が違うだけ |
| データセットそのもの | 著者が Excel で組んだもの（非公開） | 同じ公開統計から独立に組み直した | 同じ表を同じ手順で組んでも、丸めや項目の取り方の細部で小数以下は揃わない。係数が論文と桁で合って小数で合わないのはこれ |

## 覚えておくこと

- **著者のデータセットは公開されていない。** 本実装が論文の数字と桁で合って小数で合わないのは、
  係数を別のデータで推定し直しているため
- 最終年度に作れない値がいくつもある：金利3種（前年値で代用）、資本ストック（暦年変換の都合）、
  配当率の初年度（1994年度）
- データはすべて名目で、実質値はデフレータで割って作る。「断りがないデータは全て名目」
- 金融所得は市場金利ではなく SNA 内の比率で作るので、実績の財産所得とはかなり違い、
  その差が epsilon に溜まる。論文自身が「epsilon_F は近年になるほど大きくなる」と認めている
- 資金循環の3表のうち、モデルが動くのに要るのは残高と評価調整だけ（取引表は作るが使わない）
