01SFCモデルって何？

ふつうのマクロ経済モデルは「GDPがいくら」「物価がいくら」というフロー（流れ）を追いかけます。SFCモデルはそこにストック（残高）を組み込んで、誰かの支出は必ず誰かの収入、誰かの借金は必ず誰かの資産という会計の恒等式を全部満たすように作られています。

このモデルは日本経済を6つの部門に分けます。

N
非金融法人（企業。対家計民間非営利団体を含む）
CB
日本銀行
F
日銀以外の金融機関
G
一般政府
H
家計
W
海外

そして金融資産を6種類（現金・HPM／国債／預金／融資・債券／株式／保険年金）に整理し、これに金融純資産の行を足します。この 6×7 の表が、モデルの背骨です。

02何ができるの？

「もしあの政策がなかったら、日本経済はどうなっていたか」を数字で試算できます。たとえば：

  • 金融緩和がなく、国債金利が1.8%高いままだったら
  • 円安にならず、為替が高止まりしていたら
  • 政府が消費を毎年5兆円切り詰めていたら
  • 消費税10%への引き上げが4年早かったら

これを反実仮想（counterfactual）と呼びます。外生変数を変えてモデルを解き直し、実際の経路と比べるだけです。

03どういう仕組みで動くのか

データを集めるところから結果が出るまで、6つの段階があります。数字は前の段階から順に流れていきます。

外生と内生のちがい

外生変数は、モデルの外から与える数字です（為替、消費税率、労働力人口など）。内生変数は、モデルが計算する数字です（GDP、物価、賃金など）。反実仮想でいじるのは外生変数だけ。あとはモデルが勝手に決めます。

04ちゃんと動いているの？

論文が同じテストの結果を表で公表しているので、そのまま突き合わせられます。1997〜2023年度の27年間を通して回し、実績とどれだけずれるかを測ったものです（論文の数字は1997〜2023年度）。

変数論文この実装
消費デフレータ1.27%1.46%
就業者数1.60%1.51%
名目GDP1.49%1.43%
実質消費1.38%1.29%
純間接税2.36%2.34%
営業余剰5.02%4.77%
名目賃金1.54%2.07%
実質輸出4.65%4.83%
失業率48.05%43.67%

数字は「平均絶対誤差率」。小さいほど実績に近いという意味です。27年間モデルだけで走らせて名目GDPの誤差が1.4%なら、かなり良い部類です。就業者数・名目GDP・実質消費・純間接税・営業余剰・失業率は論文の数字より小さく、残りも論文と 0.5%ポイント以内に収まっています。

名目賃金だけ論文から離れているのはなぜ？ 就業者数の式には「実質賃金の変化率」が入っていて、これが 賃金 → 失業率 → 就業者数 → 賃金 という輪を作っています。この輪の強さを弱めると賃金だけよく当たるようになりますが、そのかわり物価・デフレータ・就業者数が揃って悪くなります。この実装は「賃金1本を捨てて他をとる」側、つまり論文の係数をそのまま使う側を選んでいます。

失業率の誤差が大きいのはなぜ？ 失業者数は「労働力人口 − 就業者数」という大きい数どうしの引き算で決まります。6,900万人 − 6,750万人 = 150万人。就業者数が1%（67万人）ずれるだけで、失業者数は45%ずれてしまう。論文でも48%の誤差が出ています。これはモデルの弱点として理解しておくべき点です。

06自分でシナリオを作る

やることは3つだけです。データをコピーして、外生変数を書き換えて、解き直す。

import parkmodel as pm

m, d = pm.load()
base = m.simulate(d, 1997, 2024, mode="dynamic")   # 比較の基準

alt = d.copy()
alt.loc[2013:, "GR"] -= 5000     # 実質政府消費を毎年5兆円減らす

sim = m.simulate(alt, 1997, 2024, mode="dynamic")

diff = (sim["YR"] / base["YR"] - 1) * 100
print(diff.loc[2015:2023].round(2))   # 実質GDPへの影響（％）

単位は十億円なので、5兆円は 5000 です。よく使う外生変数を挙げておきます。

IR_G実質政府投資十億円（年21,000前後）
RRB実質国債金利小数（0.006 = 0.6%）
NEER名目実効為替レート1基準。大きいほど円高

内生変数はそのままでは動かせません。 たとえば設備投資 IR_N はモデルが決める変数なので、外から −5兆円と書き込んでも上書きされます。こういうときは方程式に「アドファクター」を足します。実装例は abenomics_park.py にあります。

「アベノミクスがなかったら、実質GDPは毎年2〜4%低かった」という論文の結論を、独立に組んだデータで再現できている、という読み方になります。実質GDPの落ち込みは5年とも 0.4%ポイント以内で合い、2012〜2023年度の累計実質GDP損失は 140.8 兆円（論文 138.5 兆円）と2%差です。ここまで寄ったのは当てはまりを良くしにいったのではなく、データの作り方を一つずつ論文に合わせた結果です。何をどう合わせたかは、データセットの覚え書きの「直して揃えたもの（履歴）」にまとめてあります。

ベースラインをいつから走らせるかで結果が変わります。 論文は2010年度から走らせています（WP65 4.1）。ここを2005年度にすると、名目GDPの反応が論文の7割、賃金が6割まで弱まってしまいました。外生変数を何もいじらないベースラインでも、走らせるうちに実績から少しずつ離れていきます。起点が早いほどその「ずれ」が積み上がり、シナリオとの差＝政策の純効果がそのぶん薄まってしまうからです。論文の数字と比べるときは、論文と同じ起点にすること。

残る食い違いは実質家計消費で、論文はマイナス、この実装は年によってプラスに出ます。物価が下がるぶん実質の所得と資産が増え、消費関数がそれを拾って消費を押し上げるためです。

反実仮想では WP65 版の式を使っています。 WP65 の付録には「以下は、朴(2025c)からの主な変更点である」として5本の式の差し替えが書かれています。営業余剰を回帰式から残余計算式に変えたこと、非金融法人のポートフォリオ式を2006〜2023年で推計し直したこと、そして日銀の黒字を全額いっぺんに一般政府へ移すようにしたことの3つです。前の版では「日銀剰余金の政府移転はモデル化しない」としていたので、これは明確な設定変更にあたります。

この変更を入れると、利下げなどで日銀の金融純所得が動いたとき、その分がまるごと政府の純貸出に入るようになります。ただし当てはまり自体はほとんど変わりませんでした（表20 との平均的なずれは 1.51 → 1.46）。それでも採ったのは、WP65 の結果と比べるなら WP65 が使ったと書いている式を使うべきだからです。過去の再現（論文 表11・表12）のほうは、論文の表と直接比べるために元の版のままにしてあります。

072023年度より先を計算する

ここから先は論文の範囲外です。 朴先生は結論部で「シミュレーションは、将来のシミュレーションではなく、データ期間の範囲（1997年度〜2023年度）で反実仮想シミュレーションとしてこれを行った。これによって、難しい将来の外生変数の想定を避けられるほか、過去の外生変数として実績値が利用できることとなった」と書いています。論文2本のどこにも前向きの計算はありません。以下の想定はすべてこの実装側の判断です。

なにが難しいのか

方程式は169本そのまま使えます。問題は外生変数112本の将来値を誰かが決めないといけないことです。機械的に決まるのは11本だけ（年ダミーと時間トレンド）で、残りは想定が要ります。

最初は全部「2023年度の値のまま」で回してみました。計算は20年でも通ります。ところが中身が壊れていました。

年度政府の純貸出政府の純債務
2024−5.9兆1,009兆
2034−11.5兆526兆
2044−34.0兆251兆

毎年赤字なのに債務が消えていきます。 原因は評価調整（株や土地の値上がり益）34本でした。最終年度はたまたま大きな評価損が出ていて、それを毎年入れ続けると債務が機械的に削られていく。検算したら、ずれが毎年きっかり −51.2兆円で固定されていました。

この34本は、朴先生自身が「回帰式を作れなかった」と書いている項目です。「考えられる説明変数を用いて回帰分析を行っても、十分な決定係数をもつ信頼できる関係式を構築できない」「キャピタルゲインはバブル現象の駆動力であり、追究されるべき課題である」。著者が作れなかったものをこちらが予測できるはずもないので、ゼロと置きました。「将来の値上がり益は予測しない」という意味で、無風を予想しているわけではありません。

想定を変えると何が動くか

人口減を織り込むかどうかで比べると、このモデルの性格がよく出ます。

2033年度人口減を織り込むすべて据え置き
実質GDP552兆円556兆円
就業者数6,449万人6,533万人
失業率3.5%5.8%
名目賃金率44.342.4
名目GDP640兆円625兆円
純公債残高対GDP比228.1%235.6%

人口が減っても実質GDPはほとんど変わりません。 変わるのは名目のほうです。働き手が減る → 失業率が下がる → 賃金式の 2.414/失業率 が効いて賃金が上がる → 物価も上がる → 名目GDPだけ膨らむ。債務の対GDP比の差が名目GDPの差ほど開かないのも、債務と名目GDPが一緒に膨らんで相殺されるからです。

これが正しいかどうかは別の話です。ただ「人口減は実質ではなく名目に出る」というのが、このモデルに聞いたときの答えだということです。

08知っておいてほしいこと

係数は論文のままではない

論文の係数は著者が組んだデータの上で推定されたものです。こちらは2023年度確報から独立にデータを組んだので、そのままでは移せません（詳細は paper/plan_a_original_coefficients.md）。そこで式の形は論文のまま、係数だけ推定し直す方針を採っています。

賃金の式だけ、推定の仕方を変えている

賃金の式は、論文の係数を出発点にして、実際に何年も走らせたときの誤差が下がる方向へ少しだけ動かしています。動いたのは数歩ぶんで、自分のラグの係数は論文の値のままです。つまりこの式は自前で推定したものではなく、論文の係数を少し調整したものです。

この仕組みを入れたのは、前の版のデータ（2024年度確報）でふつうのOLSが壊れたからでした。失業率の係数の符号が逆になり、ラグの係数が1を超えて発散したのです。いまのデータではそれは起きず、ふつうのOLSでも普通に解けます。それでも残しているのは、ふつうのOLSの係数に替えると賃金の当てはまりは良くなるが、名目GDPと物価の当てはまりが落ちるためです（27年間のファイナルテストで賃金 2.09→1.67%、名目GDP 1.40→1.83%）。賃金1本のために他を犠牲にしない、という選択です。

論文の係数をそのまま使っている式が1本ある

就業者数の式は、一度は同じやり方で推定し直しましたが、推定の窓（2005〜2023年度）が短すぎて過剰適合し、賃金の輪の強さを弱めすぎていました。物価・デフレータ・就業者数が揃って悪くなるので、論文の係数をそのまま使っています。

生産関数（潜在GDP）は、論文と同じ毎月勤労統計の総実労働時間指数と経済産業省の稼働率指数で推定しています。3つの弾力性は論文と小数2桁まで揃います（政府資本 0.370、労働 0.602、稼働率×資本 0.126。論文は 0.370、0.593、0.125）。実績の労働時間と稼働率を使わずにトレンド値と定数で推定すると「資本が増えると潜在GDPが下がる」という符号になるので、そうなったときだけ論文の係数に戻す仕掛けにしてあります。

失業率に下限は置いていません

論文は UNR = UN/LF*100 で、こちらもそのままです。賃金の式に 2.414/UNR という項があり、失業率が小さくなると急になって計算が発散しやすいので、MAX(..., 2.0) のような下限を置きたくなる場所ですが、置いていません。

発散はモデルではなく計算のやり方の問題で、1回の更新幅を半分にして解き直せば、同じ式のまま解けます。ソルバーが発散した年だけ自動でそうします。

もうひとつ、解が1つとは限らないことも分かりました。1997年度から通しで解くと、2007年度に「失業率 −1.83%（就業者数が労働力人口を122万人超える）」という解と「+1.17%」という解の2つがあり、どちらも式そのものは満たしています。前者は失業者の人数が負なのでモデルの定義の外にあり、受け入れ判定で弾いています。式には手を入れていないので、方程式の照合には差として出ません。

下限を置いても問題は隠れるだけです。下限つきで解くと、失業者数が負のまま失業率だけが 2.000% に切り上がる、ということが起きます。

当てはまりは一長一短です（賃金 4.63→3.75% と改善、消費デフレータ 1.07→1.28% と悪化、表20 の再現は 1.57→1.90 と悪化）。採った理由は当てはまりではなく、論文の式のまま解けるようになったからです。 感応度を見たいときは pm.load(unr_floor=2.0) で戻せます。

論文そのものにも食い違いがある

再現していて分かったことですが、論文の中にも整合していない箇所があります。海外部門のポートフォリオ式2本は、本文と巻末のモデルコードで係数が違います（2025年版・改訂版とも）。どちらが本物かは、論文自身が載せている誤差率をどちらが再現するかで判定できて、本文のほうでした。巻末に1つ前の推定が残っています。この実装では本文の値を使います。

また、巻末のモデルコードは実際のモデルをそのまま印刷したものではなく、整理された縮約版のようです。本文に出てくる稼働率指数やトービンのqは、コードでは定数に置き換えられたり落とされたりしています。改訂版が「内生変数は171個」と書いているのに印刷されている式が169本なのも、おそらくこれが理由です。外生変数112本のほうは、この実装とぴったり一致しています。

2024年度以降は論文の範囲外

07で作った前向きの経路は、予測ではありません。外生変数112本の将来値をこちらが決めた結果であって、朴先生はこれをやっていません。とくに株や土地の値上がり益をゼロと置いているので、資産価格が動く世界のことは何も言えていません。見通しとして使うなら、金利・為替・政府支出・消費税率を自分で置き直してください（forecast.load(overrides={...})）。
