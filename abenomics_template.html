Counterfactual Simulation

アベノミクスがなかったら

この記事の数字は、朴勝俊先生の日本版ストック＆フロー一貫（SFC）マクロ計量モデルを Python で一から書き直して出したものです。方程式169本をコードに起こし、データの取得・パラメータの推定・求解・作図までを自動で回せるようにしてあります。データセットも公開統計から独立に組み直したので、論文の表と突き合わせて検算できます。
再実装の入門ガイドを読む →

「もし、あの政策をやっていなかったら」を数字で言うにはどうするか。日本経済のマクロ計量モデルを使った反実仮想シミュレーションを、はじめての人向けに解説します。使うのは2013〜{{end}}年度の{{nyears}}年間です。生産だけでなく、政府の借金がどうなったかまで見ます。最後に、消費税を動かしたらどうなるかも並べました。

01そもそも何を知りたいのか

アベノミクスの効果を測りたい、とします。いちばん素朴なやり方は「政策の前と後を比べる」ことです。2012年度の実質GDPは518兆円、2023年度は556兆円。だから38兆円ぶん効果があった——と言いたくなります。

これは間違いです。この{{nyears}}年間には、政策以外のことも山ほど起きました。世界経済の伸び、人口減少、消費税の引き上げ、コロナ。前後を比べても、そのぜんぶが混ざってしまいます。

本当に知りたいのは、「他の条件をぜんぶ同じにしたまま、政策だけ無かった世界」です。現実にはそんな世界は観測できません。だからモデルの中に作ります。これを反実仮想（counterfactual）と言います。

02やり方は「2回解いて、差を見る」

手順はたった3つです。

  1. ベースラインを解く。実際に起きたとおりの条件で、モデルを2010年度から2023年度まで走らせる
  2. シナリオを解く。政策に関わる入力だけを「やらなかった」値に差し替えて、もう一度同じように走らせる
  3. 2本の差を取る。これが政策の効果

いちばん大事な注意。比べるのはモデルの線どうしです。「シナリオ」と「実績」を比べてはいけません。

モデルには誤差があります。ベースラインも実績とぴったり同じにはなりません。シナリオと実績を比べると、その誤差が政策効果に混ざってしまいます。ベースラインと比べれば誤差は両方に同じだけ乗るので、差を取ったときに消えます。

03「やらなかった」を7つのスイッチで表す

アベノミクスは「三本の矢」と呼ばれました。金融政策・財政政策・成長戦略です。これを、モデルに入力する外生変数7本の操作に翻訳します。

矢シナリオやらなかったら、を表す操作
第一の矢
金融政策		2. 利下げなし2013年度以降、実質国債金利を1.8%ポイント高くする
3. 為替が高いまま2013年度以降、名目実効為替レートを20%ポイント高くする（円安が起きない）
4. 株価が上がらない2012年度以降、株式の評価調整（値上がり益）をゼロにする
第二の矢
財政政策		5. 2012年度の補正予算なし2012年度だけ、実質政府消費と実質政府投資を6.5兆円ずつ減らす
6. 政府消費の抑制2013年度以降、実質政府消費を毎年5兆円減らす
7. 政府投資の抑制2013年度以降、実質政府投資を毎年5兆円減らす
第三の矢
成長戦略		8. 成長戦略の効果なし2013年度以降、実質設備投資が毎年5兆円低い水準にとどまる

この7つを同時に全部かけたのが「アベノミクス全効果」のシナリオです。7つの矢が全部なかった世界、という意味になります。

数字の根拠は元の論文にあります。たとえば金利の1.8%ポイントは、民主党政権期の実質国債金利2.58%と安倍政権期の0.76%の差から来ています。為替の20%ポイントも、実際の円安幅から逆算したものです。

04コードで書くとこれだけ

「政策をやらなかった世界」を作るのに必要なコードは、驚くほど短いです。外生変数の表を書き換えるだけだからです。

# 7つのシナリオ。d は外生変数の表（年度 × 変数）
def s2(d):  d.loc[2013:, "RRB"]  += 0.018      # 実質国債金利 +1.8%pt
def s3(d):  d.loc[2013:, "NEER"] += 0.2        # 実効為替 +20%pt
def s4(d):
    for c in [c for c in d.columns if c.startswith("NEQUACG_")]:
        d.loc[2012:, c] = 0.0                    # 株の値上がり益をゼロに
def s5(d):
    d.loc[2012, "GR"]   -= 6500.0                # 単位は十億円
    d.loc[2012, "IR_G"] -= 6500.0
def s6(d):  d.loc[2013:, "GR"]   -= 5000.0      # 政府消費 −5兆円/年
def s7(d):  d.loc[2013:, "IR_G"] -= 5000.0      # 政府投資 −5兆円/年

# 全効果 = 2 から 8 を重ねがけする
def s10(d):
    for f in (s2, s3, s4, s5, s6, s7, s8):
        f(d)

そして、走らせて差を取ります。

base = model.simulate(d,     2010, 2023)   # ベースライン
alt  = d.copy(); s10(alt)
sim  = model.simulate(alt,   2010, 2023)   # やらなかった世界

効果 = sim["YR"] - base["YR"]            # 実質GDPの差

方程式は1行も触っていません。動かすのは入力の表だけです。モデルの中身（169本の連立方程式）はベースラインもシナリオもまったく同じものを使います。ここを変えてしまうと、比べているものが2つの世界ではなく2つのモデルになってしまいます。

05結果を見る

実質GDPの推移です。黒がベースライン（実際どおりの条件）、青の破線が「アベノミクスがなかった世界」。この2本の差が政策の効果です。灰色の実績は、モデルがどれだけ実績に沿っているかの参考として置いています。

{{end}}年度でベースライン{{yr_base0}}兆円に対して「なかったら」{{yr_s10_0}}兆円。差は{{yr_diff0}}兆円、率にして{{yr_pct}}%です。毎年の差を2012年度から{{end}}年度まで足し上げると{{cum10}}兆円になります。

06三本の矢のどれが効いたのか

7つのスイッチは1本ずつ切ることもできます。矢ごとにまとめた、{{nyears}}年間の実質GDP損失の累計です。

いちばん効いたのは第二の矢、財政政策です。政府消費・政府投資・補正予算を合わせて{{fiscal0}}兆円。金融政策（{{money0}}兆円）の{{fiscal_ratio}}倍あります。「アベノミクスといえば異次元緩和」という印象とは、だいぶ違う結果です。

1本ずつ見ると、小さい2本（利下げ・為替）で符号が食い違っています。どちらも金額が小さく、モデルの中で正負の経路が拮抗するところなので、データの作り方の差で符号が入れ替わりやすい場所です。大きい5本は方向も大きさもよく合っています。

利下げで実質GDPが下がる？

この再実装では「利下げなし」がプラス{{s2_cum0}}兆円、つまり金利が高いままのほうが実質GDPがわずかに高い、という結果になります。直感に反しますが、理由ははっきりしています。このモデルはストック＆フロー一貫型で、家計が1,772兆円の金融純資産を持っていることまで勘定に入れます。金利が上がると、投資は減りますが家計の利子所得が増えます。日本のように家計が巨額の純債権を持つ経済では、後者が前者を上回ることがある、というのがモデルの答えです。

元の論文でもこの経路は効いていて、だから「利下げなし」の損失はマイナス8.5兆円と、他の矢に比べて小さく出ています。符号が割れるほど拮抗している、と読むのが正確でしょう。

07政府の借金はどうなったか

ここまでは生産の話でした。では財政はどうでしょう。アベノミクスは補正予算を組み、政府消費も政府投資も増やしました。やらなければ、そのぶん借金は少なくて済んだはず——そう考えるのが自然です。

モデルの答えは逆でした。

＋{{debt10_0}}兆円{{end}}年度の純公債残高

対GDP比では {{ratio_base}}% → {{ratio_s10}}%。{{ratio_diff10}}%ポイントも悪化します。アベノミクスをやらなかった世界のほうが、借金は重かったことになります。

どこから来たのか、1本ずつ切って調べる

7つのスイッチを1本ずつ切って、{{end}}年度の純公債残高がベースラインからどれだけ動くかを見ます。プラスが借金の増加です。

歳出を絞る3本（5・6・7）は、ちゃんと借金を減らしています。合わせて{{spend3_0}}兆円。直感どおりです。

ところが、それを打ち消して余りある2本があります。利下げなし（＋{{s2_debt0}}兆円）と株価が上がらない（＋{{s4_debt0}}兆円）。この2本だけで{{s24_debt0}}兆円です。

なぜそうなるのか──2つの経路

借金の増え方は、2つに分解できます。毎年の赤字が積み上がったぶんと、持っている資産の値段が動いたぶんです。

{{table:decomp}}
シナリオ借金の増分赤字の累積資産の評価

2012〜{{end}}年度の累計、兆円。紙幅の都合で主な4本と合計のみ。

利下げなしは、まるごと利払いです。増分{{s2_debt0}}兆円がそっくり「赤字の累積」に入っています。政府は1,100兆円規模の借金を抱えているので、金利が1.8%ポイント高いと、国債の利払いは{{nyears}}年で{{s2_int0}}兆円増えます。政府自身の利子収入が{{s2_fin0}}兆円、税収が{{s2_tax0}}兆円、社会保障の収支が{{s2_str0}}兆円よくなるぶんを差し引いて、{{s2_debt0}}兆円が残ります。

「日銀からの納付金」について。国債{{debt_base0}}兆円のうち{{cb_jgb0}}兆円は日銀が持っています。日銀が受け取った利子は、経費を除いて納付金として政府に戻ります。元の論文（WP65版）はこれを「日銀の黒字は全額いっぺんに政府へ移す」という式で入れていて、この記事もそれを使っています。だから政府の利子負担は、日銀以外が持つ国債のぶんだけ、と考えるのが自然です。

ところが利下げなしのシナリオでは、この納付金がほとんど増えません（{{nyears}}年で{{s2_cb0}}兆円）。理由は日銀の国債保有の決まり方にあります。このモデルでは日銀の保有は他の部門が持った残りとして決まり、実質金利が高いと銀行などが国債を買い増すので、そのぶん日銀の保有が減ります。金利が上がった一方で保有が減り、日銀の利子収入は行って来いになるのです。政府から見ると、高い利子を払う相手が日銀から銀行に入れ替わっただけで、戻ってくる分は増えません。

株価が上がらないほうは、半分以上が「資産の評価」です。{{s4_debt0}}兆円のうち{{s4_reval0}}兆円がこちら。理由は、政府自身が株を持っているからです。年金積立金などを通じて、{{end}}年度で{{gov_eq0}}兆円。アベノミクス期の株高で、この保有株に{{nyears}}年間で{{s4_reval0}}兆円の含み益が生まれました。株が上がらなければ、その含み益は存在しません。政府の資産が{{s4_reval0}}兆円少ないぶん、帳尻は国債の発行で合わせることになります。

ここがストック＆フロー一貫モデルの持ち味です。ふつうのマクロモデルは「毎年の赤字」までしか見ません。このモデルは政府が何をいくら持っているかまで勘定に入れるので、資産価格の変化が財政に効く経路が最初から入っています。{{s10_reval}}兆円という数字は、ベースラインの政府保有株の評価益の累計と、ぴったり一致します。

2つの読み方

この結果は「緊縮しても借金は減らない」という意味ではありません。歳出を絞る3本は、実際に借金を減らしています。

言えるのはこうです。財政赤字を削って減らせる借金より、金融緩和と資産価格が押し下げていた借金のほうが大きかった。そして後者は、財政当局が「節約した」結果ではありません。

もうひとつ。分母のGDPも効いています。アベノミクスをやらなかった世界では名目GDPが1割ほど低いので、同じ借金でも対GDP比は重く出ます。借金の絶対額と対GDP比のどちらを見るかで、政策の評価は変わります。ここでは両方を並べました。

08消費税を動かしたら、借金はどうなるか

ここまでの7本のスイッチに、消費税は入っていません。別立ての実験があるからです。方向は2つ。

  • 予定どおり増税——2015年10月に10%へ。実際には2019年10月まで延期されたので、4年前倒しの世界です（元の論文のシナリオ9）。
  • 5%のまま据え置き——2014年度の8%も、その後の10%もなかった世界。こちらは論文にはなく、私の拡張です。

直感はこうでしょう。増税すれば借金は減る。据え置けば借金は増える。

モデルの答えは、両方とも違いました。

＋{{s9_debt}}兆円予定どおり増税したときの純公債残高

消費税を4年早く10%へ上げると、{{end}}年度の借金は{{debt_base}}兆円 → {{debt_s9}}兆円。わずかですが増えます。逆に5%のまま据え置くと{{debt_s5}}兆円で、{{s5_debt_abs}}兆円減ります。

アベノミクスの「株価が上がらない」では、増分の{{s4_reval_share}}割が資産の評価でした。消費税のほうは2本とも、資産の評価がきっかりゼロです。税率は政府の持っている株や年金資産の値段に直接は触らないので、動く経路が赤字の累積しかない。同じ借金の増減でも、中身がまったく違います。

増税したのに、なぜ赤字が増えるのか

赤字の中身を項目ごとに割ると、こうなります。プラスが財政の改善です。

項目予定どおり増税5%据え置き

2012〜{{end}}年度の累計、兆円。合計はモデルの政府純貸出の差と一致します（恒等式の検算）。

消費税は、ちゃんと{{s9_tin}}兆円の増収になっています。取れる税金は増えました。それでも財政が良くならないのは、それを食う支出増が2つ乗るからです。

ひとつめは国債の利子で{{s9_int_abs}}兆円。理由はモデルの1行にあります。

rB = RrB + (PC - PC(-1)) / PC(-1)
#  国債の名目金利 ＝ 実質金利 ＋ 消費者物価の上昇率

消費税を上げれば消費者物価は上がります。実質金利のほうはこのバージョンでは外から与える数字なので動きません。つまり上がった物価がそのまま名目金利に乗ります。そして政府は1,100兆円規模の借金を抱えている。わずかな金利上昇でも、かける相手が大きすぎるのです。ただし国債の半分近くは日銀が持っていて、日銀が受け取った利子は納付金として政府に戻ります（＋{{s9_cb}}兆円）。差し引きの利子負担は{{s9_int_net}}兆円です。利下げなしのシナリオでは納付金がほとんど動きませんでしたが、こちらは大きく動きます。あちらは実質金利が上がって銀行が国債を買い増し、日銀の保有が減りました。消費税のほうは物価だけが動いて実質金利は変わらないので、日銀の保有はそのまま、受け取る利子だけが増えるからです。

ふたつめは社会保障の収支で{{s9_str_abs}}兆円。増税で家計の所得が細ると、社会保険料の入りが減り、給付が増えます。所得税なども{{s9_tax_abs}}兆円減ります。

5%据え置きは、これをそっくり逆回しにしたものです。消費税の減収{{s5_tin_abs}}兆円は大きい。しかし物価が上がらないので利払いが{{s5_int}}兆円浮き（日銀からの納付も{{s5_cb_abs}}兆円減るので差し引き{{s5_int_net}}兆円）、経済が大きいので社会保障と所得税で{{s5_strtax}}兆円入ってくる。政府消費・政府投資の名目額が{{s5_gov_abs}}兆円増えるぶんを引いても、足し引き{{s5_nl}}兆円の黒字方向でした。

ここは結果がモデルの作りに強く左右される場所です。このモデルは、借金の全体が毎年その年の金利で借り換えられるものとして利払いを計算します（rB(-1) * NGBA_G(-1)）。ところが実際の国債は固定利付きで、いったん発行してしまえば物価が上がっても利払いは増えず、むしろ返済の実質的な重さは軽くなります。つまりこのモデルは「物価上昇 → 利払い増」を強めに見て、「物価上昇 → 借金の実質目減り」を見ていません。増税シナリオの結論は、この扱いにかなり寄りかかっています。

借金の絶対額と対GDP比、名目と実質。どれを見るかで「増税は財政を良くしたか」の答えが変わります。ここでは4つ全部を並べました。

5%据え置きの数字は、いちばん弱いところです。これは論文にないシナリオで、しかもモデルを拡張方向に強く押します。失業率は{{end}}年度で{{s5_unr_min}}%まで下がりました。賃金の式には「1 ÷ 失業率」という項が入っていて、失業率が小さいほど急に効きます。係数を推定した期間（1994年度以降）の失業率の最小は{{unr_data_min}}%なので、ここは推定に使ったデータの外側です。賃金と物価まわりの数字は割り引いて読んでください。

「政策をやらなかったら」の中身は仮定である

金利が1.8%ポイント高かった、為替が20%ポイント高かった——これらは論文の著者が根拠を示して置いた仮定です。別の仮定を置けば別の数字が出ます。結果の数字より、仮定の置き方のほうが議論の対象になるべきです。

モデルには誤差がある

ベースライン自体、実績を完全には再現しません。2010〜2023年度の平均絶対誤差率は実質GDPで1.5%、消費デフレータで1.0%、賃金で2.1%です。差を取れば誤差の多くは相殺されますが、ゼロにはなりません。

効果の大きさは「モデルの構造」が決めている

財政政策がいちばん効くという結果も、利下げの符号が割れるのも、このモデルがそう組まれているからです。別の型のモデル（たとえば家計の金融資産を明示的に持たないもの）なら、違う答えが出ます。「日本経済の真実」ではなく「このモデルに聞いたときの答え」として読むのが正確です。

それでも反実仮想に意味があるのは、仮定と計算がぜんぶ明示されているからです。前後比較のように「何が混ざっているか分からない」ということがありません。どの仮定に納得できないかを指差して議論できる——それが、この方法のいちばんの取り柄です。
