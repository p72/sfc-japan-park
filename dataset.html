朴モデルのデータセット

朴勝俊のストック＆フロー・一貫マクロ計量モデルが何のデータを、どこから、どう加工して使っているかを、3本の論文の記述からまとめた覚え書き。末尾に本実装（Python版）との対応と食い違いを置く。

3本の論文とデータの系譜

  • 朴(2025c)「発展型日本版ストック＆フロー・一貫マクロ計量モデルの構築」

    関西学院大学総合政策学部 WP No.62 ／ 2025年9月

  • 朴(2026a)「金融資産・負債の蓄積とマネー量の変化を把握できるマクロ計量モデルの構築」

    No.62 の改訂版 ／ 2026年1月22日

  • 朴(2026)「いわゆる『アベノミクス』がなかった場合の日本経済」

    WP No.65 ／ 2026年4月

3本とも同じ一つのデータセットを使っています。2025c で作られ、2026a はその記述を整え、WP65 はそれを反実仮想に使った、という関係です。

論文データについての位置づけデータ節の差
2025cデータセットを新規に構築。2章「使用するデータセット」と巻末の変数表で全容を記述—
2026a同じデータセット。データ節の本文は文言の整理のみ（「29年ぶん」「家計は住宅を…」の補足など）実質差なし
WP65同じデータセット。推定期間を式ごとに再設定（例：法人ポートフォリオ 2006–2023）。営業余剰を残余式にしたため、統計上の不突合 SD をモデル内で使う同じ元データ

2025c と 2026a のデータ節を機械的に突き合わせた結果、差分は段落の並べ替えと補足の一文だけで、出典・期間・加工法に変更はありませんでした。WP65 は本文2章が「2023年度国民経済計算」を使ったと書くだけで、データ節そのものは持ちません（本文全文と付録で確認）。

SNA の原表から、モデルが読める形になるまでに4段階あります。

純計・評価調整・金

  • 純計：各部門・各資産を「資産−負債」の純額で持つ。変数名は N + 資産 + A + _部門（例 NEQUA_H）。金融純資産は負債側なので NNFWA は純資産がプラスの部門でマイナス
  • 評価調整（キャピタルゲイン）は統計に無いので、評価調整_t ＝ 残高_t − 残高_{t−1} − 取引_t で作る。残高と取引の両方が要るのはこのため
  • 金（貨幣用金・SDR）は対応する負債を持つ部門が無いので GSH の部門合計がゼロにならない（2023年度で9,115十億円）。便宜上、全額を日銀が保有すると仮定
  • モデル内では取引表は使わない（残高と評価調整だけで動く）

「金融機関の内訳」表の組み方は確報の版で違います。2024年度確報は1シートに資産側と負債側が左右に並びますが、2023年度確報は資産側（ss62 / s242）と負債側（ss63 / s243）が別ファイルです。列を番号で決め打ちすると、日銀の負債側に別の列（その他の金融仲介機関の資産側）を当ててしまい、発行銀行券と日銀当座預金が丸ごと落ちて、他金融機関 F が鏡像でずれ、rL と金融所得を通じて全部門に波及します。本実装は見出しの「中央銀行」の位置から列を探し、見出しが1つなら負債側のファイルを別に取りに行きます。部門ごとの縦計＝0 という検算は作り方から必ず通るので、この取り違えは捕まえられません。残高の検算に「日銀の現金・HPM が他部門の保有を打ち消す負値か」を入れてあります。

SNA から計算で作る系列

公表値をそのまま使うのではなく、著者が定義式で作った系列です。ここに論文の「作法」が一番出ます。

金利・配当率（論文 表6）

市場金利の統計は使いません。「その資産を主に持つ部門の利子・配当 ÷ その資産の残高」で、SNA の中だけから作ります。利子は「前年度末の残高 × 前年度に決まった金利」で当年度に受け払いされると考えるので、t年度の金利 = (t+1年度の利子) ÷ (t年度末の残高)。最終年度の値が作れないので、2023年度は2022年度の値で代用。

記号何の利回り分子（部門・項目）分母
rH現金・HPM—ゼロとする（日銀当座預金の付利もゼロ）
rB国債短証一般政府の財産所得（支払）利子 [pp.26–27]国債発行額 −NGBA_G
rM預金家計の財産所得（受取）利子 [pp.30–31]家計の預金 NDEPA_H
rL融資・債券金融機関の財産所得（受取）利子 [pp.24–25]金融機関の融資債券純保有 NLBDA_F
chi株式配当非金融法人の配当純受取（法人分配所得＋海外直接投資再投資収益、受取−支払）[p.22, p.34]前期の NEQUA_N（負値÷負値）

実質化はいずれも消費デフレータ PC を差し引く（RrB = rB − PC）。

金融所得と調整項

  • FINCOME_X = rB·NGBA_X(−1) + rM·NDEPA_X(−1) + rL·NLBDA_X(−1) + chi·NEQUA_X(−1) + psi·NPENA_X(−1)。全部門に同じ利回りを当てるので実績の財産所得とは食い違い、その差は貯蓄の調整項 epsilon_X が吸収する
  • GAPNL_X：資本勘定から計算した純貸出と金融勘定の純貸出との差。日銀は GAPNL_CB = NL_CB − FINCOME_CB で、大部分が政府への納付金に相当するが 2025c/2026a はモデル化しない（WP65 で政府移転に変更）
  • KCG_X = Kn_X − (Kn_X(−1) + In_X − D_X)：資本ストックの調整項
  • STR_GAP、YR_GAP：社会移転と実質GDPの合計開差
  • 年金受給権調整 CPEN、営業余剰の部門シェア SB2_X、安全資産の保有シェア（GSH/GB/DEP の3分割）なども実績から作った外生変数

いまも違うもの 差あり

作り方が論文に書いてあるものは、すべて論文どおりに揃えました（下の履歴）。残っているのは、論文に作り方が書かれていないか、そもそも同じ数字にはならない性質のものです。

項目論文本実装どう違うか
外国人純就業者 N_W出典は「労働力調査」とあるが、系列は公表されていない論文自身の関係式 W = WB_N/N_N = WB_W/N_W から N_W = WB_W·N_N/WB_N で導出著者がどう作ったか不明。論文の定義とは整合するが、同じ数字とは限らない

覚えておくこと

  • 著者のデータセットは公開されていません。本実装が論文の数字と桁で合って小数で合わないのは、係数を別のデータで推定し直しているためです
  • 最終年度に作れない値がいくつもあります：金利3種（前年値で代用）、資本ストック（暦年変換の都合）、配当率の初年度（1994年度）
  • データはすべて名目で、実質値はデフレータで割って作ります。「断りがないデータは全て名目」
  • 金融所得は市場金利ではなく SNA 内の比率で作るので、実績の財産所得とはかなり違い、その差が epsilon に溜まります。論文自身が「epsilon_F は近年になるほど大きくなる」と認めています
  • 資金循環の3表のうち、モデルが動くのに要るのは残高と評価調整だけです（取引表は作るが使わない）
